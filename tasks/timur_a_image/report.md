## 1. Введение
Сглаживание изображений — это фундаментальная операция в области обработки изображений, которая применяется для устранения шума и смягчения резких изменений интенсивности. В данной работе был разработан алгоритм сглаживания с использованием усредняющего фильтра (боксового фильтра) и выполнена его параллелизация с помощью технологии MPI для повышения скорости обработки больших изображений.

2. Постановка задачи
Задача состояла в применении усредняющего фильтра заданного размера к изображению в градациях серого. Значение каждого пикселя результирующего изображения вычисляется как среднее арифметическое значений пикселей в квадратной окрестности (ядре фильтра) вокруг соответствующего пикселя исходного изображения.
Входные параметры:
Изображение, представленное в виде одномерного массива типа uint8_t
Ширина (width) и высота (height) изображения
Размер ядра фильтра (kernel_size) — нечетное положительное число
Результат:
Обработанное изображение тех же размеров после применения фильтра
Особенности реализации:
Для граничных пикселей, где окно выходит за пределы изображения, используется стратегия отражения (clamping)
Ядро имеет нечетный размер для обеспечения симметричности
3. Последовательный алгоритм
Последовательная реализация алгоритма (файл ops_seq.cpp) служит базовой версией для сравнения производительности.
Основные шаги алгоритма:
Проверка корректности входных данных (размеры изображения, размер ядра)
Создание выходного массива того же размера, что и входной
Для каждого пикселя изображения:
Определение типа пикселя (внутренний или граничный)
Для внутренних пикселей: вычисление суммы значений в окрестности и деление на количество пикселей в окне
Для граничных пикселей: использование отраженных координат для соседей, вычисление суммы по доступным пикселям
Возврат обработанного изображения
Оптимизация: Раздельная обработка внутренних и граничных пикселей позволяет минимизировать количество проверок границ для большинства пикселей.
4. Параллельный алгоритм (MPI)
Параллельная реализация (файл ops_mpi.cpp) использует декомпозицию данных по строкам изображения.

## 4.1. Распределение данных
Корневой процесс (rank 0) считывает параметры задачи и данные изображения
Параметры рассылаются всем процессам с помощью MPI_Bcast
Изображение разбивается на блоки строк между процессами с добавлением перекрывающихся областей (overlap) размером в радиус ядра
Данные распределяются с использованием MPI_Scatterv
## 4.2. Локальные вычисления
Каждый процесс обрабатывает свой блок строк:
Для каждой строки в локальном блоке (без учета перекрытий) выполняется сглаживание
Для внутренних пикселей блока используется оптимизированная обработка без проверки границ
Для пикселей вблизи границ блока применяется функция отражения координат
## 4.3. Сбор результатов
Обработанные данные собираются на корневом процессе с помощью MPI_Gatherv, после чего формируется итоговое изображение.

## 4.4. Особые случаи
Если количество процессов превышает количество строк изображения, некоторые процессы не получают данных
Обработка глобальных границ изображения выполняется единообразно на всех процессах
5. Форматы данных
Вход: Структура TaskData, содержащая:
data: массив пикселей (uint8_t)
width, height: размеры изображения (int)
kernel_size: размер ядра (int)
Выход: Структура TaskData с обработанным изображением
Тестовые данные: Использовались как синтетические изображения, так и загружаемые из файлов
